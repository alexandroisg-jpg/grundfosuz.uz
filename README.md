# Grundfos Uzbekistan UZ

Исходный код независимого каталога промышленного оборудования Grundfos для Узбекистана.

- Работающий сайт: https://grundfosuz.uz/
- Репозиторий: https://github.com/alexandroisg-jpg/grundfosuz.uz
- Телефон: +998 90 900 88 05.
- 17 позиций, 14 предварительных цен и справочник 53 промышленных серий.

## Размещение

Сайт опубликован через ChatGPT Sites на инфраструктуре Cloudflare. Домен grundfosuz.uz
подключён к этой публикации. GitHub хранит исходный код; GitHub Pages и автоматическая
публикация при push сейчас не настроены. Изменения репозитория сами по себе не меняют
работающий сайт. Исходная опубликованная ревизия: f839a761d184b451964ce4f2829006d4ce256204.

Конфигурация существующей публикации сохранена в `.openai/hosting.json`. Для выпуска
обновлений используется тот же проект Sites. Секреты и внутренние закупочные расчёты
в публичный репозиторий не включены.

## Запуск

Требуются Node.js 22.13+ и pnpm версии из package.json.

```bash
git clone https://github.com/alexandroisg-jpg/grundfosuz.uz.git
cd grundfosuz.uz
bash start-local.sh
```

Адрес локального просмотра: http://localhost:5173. Сборка: `npm run build`.

## Каталог

- `data/products.json` — модели, характеристики, публичные предварительные цены и источники.
- `data/families.json` — справочник серий.
- `components/catalog.tsx` — поиск, фильтры, карточки и список подбора.
- `app/products/[id]/page.tsx` — отдельные серверные страницы товаров.
- `docs/SUPPLIER_IMPORT.md` — загрузка номенклатуры и прайса.

Цены предварительные; наличие, комплектация, применимые условия НДС и сроки поставки
уточняются перед заказом. Список подбора сохраняется в браузере, копируется или
выгружается в TXT. Серверный приём заказов и онлайн-оплата не подключены.

## Поисковые системы

- https://grundfosuz.uz/robots.txt
- https://grundfosuz.uz/sitemap.xml — главная и 17 страниц товаров.
- Canonical ведут на https://grundfosuz.uz; модели и цены доступны в серверном HTML.
- `node scripts/verify-search.mjs` проверяет публикацию.
- `node scripts/verify-search.mjs --submit` отправляет URL через IndexNow только после
  успешной проверки. Принятие URL не означает включения в поисковую выдачу.

Google Search Console и Яндекс Вебмастер требуют отдельного подтверждения прав
владельца. Актуальный результат подачи описывается в `docs/SEARCH_STATUS.md`.

Проект не является официальным сайтом или подтверждённым дилером Grundfos.
Товарные знаки и изображения принадлежат правообладателям.
