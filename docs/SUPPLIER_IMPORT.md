# Загрузка промышленного каталога и прайса

Импорт: `node scripts/import-catalog.mjs /путь/прайс.json`

Записи добавляются или обновляются по полю `id`. Импорт атомарный: весь входной файл проверяется до изменения каталога; прежний файл сохраняется в `.catalog-backups`. Полная замена: добавьте `--replace`. Эти резервные копии не предназначены для публикации.

Формат — JSON-массив. За образец возьмите одну запись из `data/products.json`.

Обязательные поля: `id`, `name`, `category`, `description`, `price`, `priceType`, `source`, `sourceName`, `checkedAt`, `specs`.

Категории:
- `multistage` — многоступенчатые CR/CRE/CRI/CRN и горизонтальные CM/CME;
- `endsuction` — консольные NB/NK и исполнения;
- `inline` — TP/TPE и насосы инженерных систем коммерческих объектов;
- `boosters` — промышленные насосные станции Hydro;
- `dosing` — дозирование и водоподготовка;
- `wastewater` — промышленные сточные воды;
- `borehole` — промышленное скважинное водоснабжение SP;
- `controls` — автоматика.

`price` — целое или дробное число в сумах; `null`, если цена не подтверждена. Не используйте ноль вместо неизвестной цены.

`priceType: "reference"` — цена стороннего продавца. `priceType: "sale"` — собственная продажная цена; для предварительной цены укажите `preliminary: true`. Импорт не меняет тип цены автоматически. `priceFrom: true` — источник указывает «от»; этот признак должен сохраняться.

`source` — HTTPS-ссылка на источник. `sourceName` — его название. `checkedAt` — дата проверки YYYY-MM-DD. `sourceUpdatedAt` — дата обновления объявления, если известна. `priceNote` — существенное пояснение к цене.

`article` — точный артикул производителя; не выводится из названия модели. `specs` — объект «параметр»: «значение с единицей». `image` — HTTPS-ссылка или путь `/images/...`. Для общей фотографии серии укажите `imageNote`.

Для полноценного каталога поставщик должен передать все актуальные артикулы, исполнения 50 Гц для Узбекистана, характеристики, фотографии, документацию, совместимость запчастей по изделию и дате производства, цены с условиями НДС, сроки и остатки. Текущая версия не синхронизируется с поставщиком автоматически.

После изменения: `npm run build`. Публикация — отдельный шаг. Внешние заявки, оплата и учёт склада пока не подключены.
